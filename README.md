# Move — iOS fitness app

A native SwiftUI fitness discovery app inspired by the supplied reference: dark surfaces, vivid lime accents, activity discovery, event details, schedule, progress and profile.

## Run

Open `appios.xcodeproj` in Xcode 15 or newer, select the `appios` scheme and run on an iPhone simulator (iOS 17+).

The project is self-contained and uses SwiftUI and SF Symbols. No third-party packages are required.
